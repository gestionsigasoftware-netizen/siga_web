# Página "no encontrado" (404) — web y PWA — 2026-09-07

## Contexto

Pendiente detectado en la ronda de QA de producción del 2026-09-04
(`docs/auditorias/qa-produccion-2026-09-04.md`): tanto la web como la
PWA redirigían en silencio a `/` (o `/app`) para cualquier URL
inválida, sin avisar al usuario que la dirección no existía.

## Construido

**Web (`siga-nacional`)**: nuevo `src/pages/NotFound.jsx` (mismo estilo
que `Legal.jsx`/`Ayuda.jsx` -- fondo, tipografía y `Footer`
compartidos), con enlaces a "Ir al inicio" e "Iniciar sesión".
`App.jsx`: la ruta comodín (`path="*"`) pasó de
`<Navigate to="/" replace />` a `<NotFound />`; se quitó el import de
`Navigate` (quedó sin uso).

**PWA (`siga-pwa-nacional`)**: mismo patrón, `src/pages/NotFound.jsx`
con el estilo `app-shell`/`app-screen` ya usado en el resto de la app,
enlace "Ir al inicio". `App.jsx`: mismo cambio de ruta comodín.

## Verificación

`npm run build` sin errores en ambos proyectos. No se probó
visualmente en navegador (cambio puramente de enrutamiento
frontend, sin datos ni backend de por medio) -- si se quiere confirmar
visualmente, basta con levantar `npm run dev` en cualquiera de los dos
proyectos y visitar una URL inexistente.
